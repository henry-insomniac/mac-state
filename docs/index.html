没有刘海屏也能使用吗？

可以。无刘海显示器使用顶部中央入口；是否在全屏时显示，可在设置中选择。

小组件和传感器有哪些限制？

小组件刷新由 macOS 调度。本版提供 macOS 热状态，不提供温度、风扇转速及磁盘实时吞吐读数。
